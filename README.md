# Homebrew tap for HelioFITS Studio

```
brew install --cask GillySpace27/tap/heliofits-studio
```

Apple Silicon and Intel Macs on macOS 14 (Sonoma) or later. Updates: `brew upgrade --cask heliofits-studio`.
Windows and Linux downloads, and everything else: <https://gilly.space/heliofits-studio/>.
